# Pointer? Apaan tu?

Kalo kalian mikirnya sama seperti saya pas ketemu sepotong kode gini:
```
int a = 10;
int *p = &a;
```
> Hah apaan tu? integer dikali sama _p_? <br/>
> Apalagi itu _'dan A'_? Nyanyi nih?

<Image src={myImage} alt="folders" />

Yap kita sama. Tapi apa iya benar begitu?<br/>
Simbol _bintang_ atau _Asterisk_ ini sering kali kita tau dipake buat operasi aritmatika perkalian.
Ternyata di C, ini bisa punya makna lain. Tergantung cara pakainya gimana. Rupanya ada istilah yang disebut dengan **Pointer**.
